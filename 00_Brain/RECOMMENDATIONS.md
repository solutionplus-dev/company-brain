# Recommendations

The owner's advisory register. Only the daily and weekly runs give out `REC-` numbers. A block looks like this:

```
### REC-<yyyy>-<nnn> · U<urgency 0-3>·S<size 0-3> · <entity code or both> · <category> · `short-key`
- **What:** one sentence.
- **Why:** the evidence, with paths.
- **Status:** proposed | accepted <date> | declined <date> | done <date>
```
