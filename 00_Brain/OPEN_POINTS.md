# Open points

Contradictions between sources, and decisions that are not an agent's to take. Never pick a side: write both sources. Only the weekly run closes a point, and only on a document, a ledger entry or the owner's written answer.

| # | Opened | The point | Source A | Source B | Whose decision | Mark |
|---|---|---|---|---|---|---|

Mark: `A` needs the owner this week · `B` needs the owner sometime · `C` waits for a document.
