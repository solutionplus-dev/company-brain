# Evaluations — the brain measures itself

Written every Tuesday by the daily run (`00_Brain/SCHEDULES/daily.md` Step 3b), one file per week: `<yyyy>-W<ww>.md`.

Each file starts with one score line, so weeks can be compared:

`sources read <n>% · answer-sheet questions answered <n>% · search <x> of <y> · owner corrections <n> · journal lines without a document <CODE> <n> / <CODE> <n>`

then the change against last week and the three worst findings, each with its evidence. Sunday's block turns those into proposals in `../IMPROVEMENTS.md`; the Sunday after checks whether an applied change moved the number. An improvement that cannot be seen in next week's score is a guess.

`QUESTIONS.md` holds the standing search questions (`scripts/brain check`).
