# Credits

This template was written from a brain that a small company runs itself on. No data, client, person or figure of that company is in it; the example company is invented.

Ideas we are grateful for:

- **GTM Brain** (MIT licence): a company brain for go-to-market teams, as plain files an agent can query. This template takes the same starting point and extends it to the whole company.
- **Brains that keep their routines as files, log every run and propose their own improvements**: we met that pattern in other people's work before building ours. No text or code from any other project is included here; everything in this repository was written for it.
- **EmbeddingGemma** by Google, run through **MLX**, for the optional local search by meaning. The model is downloaded by `tools/index/embed/setup.sh` under its own terms; it is not part of this repository.
