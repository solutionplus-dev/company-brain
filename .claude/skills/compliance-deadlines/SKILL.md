# Deadlines

1. Sources: `00_Brain/DEADLINES.md`, `finance/OBLIGATIONS.md`, `scripts/brain records kind=deadline`.
2. A date read from the document is `CONFIRMED`. A date from memory, a phone call or arithmetic is `NEEDS VERIFICATION`, with what would confirm it.
3. Rank by what a miss costs (a penalty, a lapsed licence, a lost right), not by how soon.
4. A new recurring duty goes to `finance/OBLIGATIONS.md` with its mail signal, so the daily run recognises the reminder.
5. What a deadline legally requires is a question for the adviser; write the question.
