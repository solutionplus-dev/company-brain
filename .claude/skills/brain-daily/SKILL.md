# Daily run

The routine is the file `00_Brain/SCHEDULES/daily.md`. Read it and execute it exactly; where this skill and that file differ, the file wins.

What makes a run good:

1. **Skeleton first.** Create the day's log with the empty answer sheet before reading anything, so an interrupted run leaves evidence.
2. **Preflight honestly.** Test every source in `00_Brain/SOURCES.md`. A failed source is "not read" everywhere it matters: answer sheet, log, routine log, final message.
3. **Search by sender, not by skimming subjects**, for bank and authority mail.
4. **One legal entity at a time** for anything with money in it.
5. **Tomorrow's page is at most seven actions**, the costliest first.
6. **End with the routine-log entry.** A run without it did not happen.
