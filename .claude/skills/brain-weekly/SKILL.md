# Weekly run

The routine is the file `00_Brain/SCHEDULES/weekly.md`. Read it and execute it exactly.

1. **Part A first.** The owner reads the week ahead even if everything after it fails.
2. **Cleanup never deletes.** It folds (month and year rollups), stages register rollovers as proposals, and lists what the owner might remove with the exact command.
3. **The dream proposes and applies nothing.** Five buckets, at most three entries each, every entry with evidence and the exact change.
4. **Only a written yes applies an improvement, and the weekly run applies none:** Monday evening's daily block does.
