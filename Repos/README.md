# Repos — links to other brains and code

Links only, never copies (`ln -s <path> Repos/<name>`). The index does not walk into this folder: each linked brain has its own index and its own routines, which the core's daily and weekly runs execute (Step 4 and Part F).

| Link | What it is | Its routines |
|---|---|---|

Client project brains go under `Repos/clients/<slug>`.
