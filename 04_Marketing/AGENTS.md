# 04_Marketing — rules for agents working in marketing

Read the root `AGENTS.md` first; nothing here weakens it. Then the base documents in `BASE/`, which every marketing, website, outreach or sales task reads first.

```
04_Marketing/
├── BASE/                 STRATEGY.md · ICP.md · MARKET.md · VOICE.md
├── Brand/                logo, colours, type; the design system or a link to it
├── Content/              drafts and finished pieces
├── Campaigns/LOG.md      what ran, when, which entity paid
└── Reports/<yyyy>/<yyyy-mm>/REPORT_<yyyy>-W<ww>.md
```

1. **Claims need a source.** Every fact, figure, client name and quote has a source in this brain. No metric nobody measured. No badge without the certificate.
2. **Agents draft; people publish.** Nothing is posted, scheduled, sent or paid by an agent.
3. **Positioning is the owner's.** Where `BASE/` shows an open question, write from it and show the question; never pick an answer.
4. **One design system, linked, never copied.**
5. **Which entity pays a marketing cost** is decided per receipt and recorded in `Campaigns/LOG.md`.
